# 作品集截图清单

请从自己电脑真实运行的 Streamlit 网页截屏，不要用示意图片代替真实成果。建议先按 `Win + Shift + S`，选择矩形截图区域。

## 建议准备的 5 张截图

1. **01_overview.png｜经营总览**
   - 展示 KPI 卡片、GMV 趋势或品类表现图。
   - 尽量让页面标题和主要数字同时出现。

2. **02_sku_diagnosis.png｜单品诊断**
   - 选择 SKU0021 或 SKU0029。
   - 展示销售趋势、流量/转化信号及价格或库存信息。

3. **03_promotion_5pct.png｜促销情景 A**
   - 选择 SKU0021，折扣 5%，销量提升假设 20%。
   - 截图保留输入参数和模拟结果。

4. **04_promotion_25pct.png｜促销情景 B**
   - 同一 SKU，将折扣改为 25%，销量提升假设仍为 20%。
   - 与情景 A 对比毛利额、毛利率和预算状态。

5. **05_quality_check.png｜质量检查**
   - 展示终端的“17/17 项通过，0 项失败”以及报告保存位置。
   - 避免截图里出现隐私路径之外的个人信息或任何 API 密钥。

6. **06_priority_table.png｜商品运营优先级（可选）**
   - 展示优先级分数、优先级理由和建议动作。

## 图片保存位置

在项目根目录创建 `docs/screenshots/`，将截图保存到此目录。README 中使用相对路径引用，例如：

```markdown
![经营总览](docs/screenshots/01_overview.png)
```

截图应反映你实际运行的应用和模拟数据，不要伪造增长、业务收益或用户评价。
