# 简历项目描述（请按真实实现选用）

## 推荐项目名称

**3C 数码电商经营分析与采销决策工作台（个人项目）**

技术栈：Python、Pandas、Streamlit、Plotly、CSV、规则路由与本地质量评测

## 简历版本（真实、保守）

- **经营分析体系搭建：** 基于 100 个模拟 SKU、90 天日级销售记录构建 3C 品类经营数据集，计算 GMV、毛利额、毛利率、转化率和客单价，实现周期环比、品类排名、GMV 下滑 SKU、竞品价差与库存风险分析。
- **运营决策辅助：** 使用 Streamlit 构建交互式经营工作台，包含单品诊断、促销利润情景模拟和商品运营优先级；将价格差、库存覆盖、销售变化等信号整合为规则化排查线索。
- **质量评测与口径校验：** 编写本地评测脚本，对数据完整性、核心计算公式、周期对比、SKU 排序、竞品价差、库存风险和促销约束进行自动检查；开发环境一次评测 17/17 项通过。

## 关于 Agent 的表述

当前版本使用关键词/规则路由选择固定分析页面，不调用大模型 API。若面试官问到 Agent 技术，应明确说明这是一个本地规则驱动的 Agent 原型/经营分析工作台，尚未完成 LLM 自主规划和推理。后续接入本地模型并完成工具调用与评测后，再补充对应能力描述。

## 不要这样写

- 不要声称给京东或真实商家带来 GMV 增长、提升转化率或降低成本。
- 不要把模拟数据描述为真实平台数据。
- 不要写“准确预测促销销量”或“自动决定最优定价”，因为当前销量提升是人为输入的情景假设。
- 不要声称已实现多 Agent、自主推理或真实在线部署，除非你后续确实完成了实现和测试。
