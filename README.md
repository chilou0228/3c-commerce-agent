# 3C 数码电商经营分析与采销决策工作台

> 面向 3C 数码品类的本地经营分析原型。使用模拟电商数据，提供经营概览、品类分析、SKU 异常排查、竞品价差、库存风险、促销利润情景模拟和商品运营优先级。
>
> **重要说明：** 当前版本是基于 Python 分析工具与规则路由的本地原型，不调用收费大模型 API。自然语言问题通过关键词/规则路由到固定分析页面；不要将当前版本描述为已经具备大模型自主推理能力。所有业务数据均为模拟数据，不代表京东或任何真实商家。

## 项目背景

电商采销/运营人员需要同时观察销售规模、利润、流量转化、竞品价格和库存状态。单独查看报表往往难以快速确定“先排查哪个商品、为什么需要排查、有哪些约束”。本项目将常见经营分析流程整合到一个可交互的网页工作台中，并用确定性计算和质量检查降低指标口径错误的风险。

## 功能模块

- **整体经营概览：** GMV、毛利额、毛利率、访客、订单、转化率、客单价等指标。
- **周期经营对比：** 对比最近 7 天与前 7 天，展示环比变化。
- **品类经营分析：** 按品类汇总 GMV、销量与毛利表现。
- **商品下滑诊断：** 根据两个相邻周期的 GMV 变化，识别下滑 SKU。
- **竞品价格分析：** 计算本商品标价相对竞品价格的差异，并提供简单单位毛利测算。
- **库存风险预警：** 展示缺货/滞销风险、库存覆盖天数与供应商交期。
- **单品诊断：** 将销售走势、流量/加购/转化信号、价格和库存信息放在同一页面，生成规则化排查线索。
- **促销利润模拟：** 调整折扣、假设销量提升、商家单件补贴、预算上限和最低毛利率，计算促销情景指标。
- **商品运营优先级：** 汇总 GMV 下滑、绝对损失、竞品价差和库存风险，输出可解释的规则评分与建议动作。
- **质量检查：** 自动验证数据完整性、指标公式、分析工具排序、促销敏感性与工具白名单。

## 技术栈

- Python 3.12
- Pandas：数据处理与经营指标计算
- Streamlit：交互式网页界面
- Plotly：图表展示
- CSV：本地模拟业务数据
- 自定义 Python 函数：提供可复用的经营分析工具

## 数据说明

模拟数据覆盖 4 个 3C 品类：手机、笔记本电脑、平板电脑、耳机。

- 商品：100 个 SKU
- 销售：9,000 条日级 SKU 记录，覆盖 90 天
- 竞品价格：100 条快照
- 库存：100 条快照
- 数据日期：2026-07-26 至 2026-10-23

模拟数据集的一个本地检查结果：90 天 GMV 为 ¥267,293,117.98，毛利额为 ¥59,545,342.52，整体毛利率约 22.28%。这些数值仅用于演示，不能作为真实平台经营结果。

## 快速启动（Windows + VS Code）

确保项目文件位于同一个项目根目录，包含 `app.py`、`agent_tools.py`、`generate_data.py` 和 `evaluate_project.py`。

### 1. 创建并激活虚拟环境

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 2. 安装依赖

```powershell
python -m pip install -r requirements.txt
```

### 3. 生成模拟数据

仅在项目的 `data/` 目录不存在或需要重新生成数据时执行。重新生成会覆盖/重建练习用 CSV，请先备份自己修改过的数据。

```powershell
python generate_data.py
```

### 4. 启动网页

```powershell
python -m streamlit run app.py
```

终端显示本地地址后，在浏览器打开（通常为 `http://localhost:8501`）。保持终端开启以维持网页服务；按 `Ctrl+C` 可停止。

### 5. 运行质量检查

在另一个 VS Code 终端执行：

```powershell
python evaluate_project.py
```

脚本会在 `reports/` 中生成 `quality_evaluation.csv` 和 `quality_evaluation.txt`。

## 质量检查结果

在开发环境的一次本地检查中，17/17 项检查通过，0 项失败。覆盖内容包括：

- 商品/SKU 数量、销售行数和日期覆盖；
- 每个 SKU 每天一条记录、关键字段完整性；
- GMV 与毛利额公式一致性；
- 经营概览和周期环比的独立复算；
- 客单价变化字段口径；
- 品类汇总、SKU 下滑排序、竞品价差公式、库存风险排序；
- 促销折扣敏感性、预算约束和未知工具拒绝。

这不是对浏览器视觉表现的自动化测试，也不是大模型推理评测。提交作品集前，建议重新在本机运行评测，并保留实际生成的报告。

## 分析边界与后续方向

- 数据为模拟数据，结论用于演示分析流程，不代表真实业务业绩。
- 竞品价格差异不等于用户一定会因降价而购买；价格比较前应核对同规格、到手价、优惠权益和采集时点。
- 促销销量提升率是手动设定的情景假设，不是模型预测；模拟未包含所有平台佣金、物流、退货、税费及投放成本。
- 规则评分用于安排人工排查顺序，不是统计预测，也不构成因果结论。
- 当前版本没有接入大模型 API。后续可考虑在本地通过 Ollama 等方式尝试本地模型与工具调用，但需要单独评测模型能力与资源占用。
